# Fiches CP - correspondances grapheme-phoneme

## Parcours CP dans l'application

Le bouton **Ajouter le parcours CP**, depuis le tableau de bord, cree un dossier
de 31 fiches illustrees : francais, mathematiques, questionner le monde, arts,
EPS, EMC et anglais. Elles utilisent Groupe 1 et les Series 1 a 31, sans
combinaison en double. Un nouvel appui sur le bouton ajoute uniquement les
series absentes au dossier existant.

Les Series 26 a 29 prolongent le parcours avec les sons `b/d/g`, les syllabes
`pa/ta/sa`, le vocabulaire des objets et les milieux de vie des animaux.
Les Series 30 et 31 alternent volontairement image et mot a lire.
Chaque fiche reste modifiable, exportable et imprimable separement.

Ce parcours est une base d'entrainement sur les attendus fondamentaux du CP,
pas une progression prescrite : adaptez l'ordre et le vocabulaire a votre
methode de lecture et a votre classe.

Ces trois fiches proposent une entree progressive dans les correspondances entre
la premiere lettre entendue et sa graphie. Elles sont des propositions a adapter
a la progression de classe : elles ne reproduisent aucun contenu Lexidata.

| Fichier | Combinaison Lexidata | Contenu |
| --- | --- | --- |
| `cp-g1-s1-voyelles-a-i-o.json` | Groupe 1 - Serie 1 | Voyelles `a`, `i`, `o` |
| `cp-g1-s2-voyelles-e-u.json` | Groupe 1 - Serie 2 | Voyelles `e`, `u` |
| `cp-g1-s3-consonnes-m-l-r.json` | Groupe 1 - Serie 3 | Consonnes `m`, `l`, `r` |

Dans Lexidatelier, ouvrez une fiche vide puis choisissez **Importer** pour
charger l'un de ces fichiers. Les douze associations sont alors modifiables
avant impression en PDF.

Les illustrations sont chargees depuis [OpenMoji](https://openmoji.org/),

Une connexion internet est necessaire pour les afficher ; l'import d'images
locales dans l'editeur permet ensuite de rendre les fiches autonomes.
