# Classe **Active** 💬 **Application web de suivi de classe** — single-file HTML, 100 % côté client, sans serveur, sans cookie tiers, sans télémétrie commerciale. 🔗 [Forge des Communs Numériques Éducatifs](https://forge.apps.education.fr/lelabodecharlie/classe-vibe) · 📄 [Licence GPLv3](./LICENSE) · 📜 [Changelog](./CHANGELOG.md)
--- ## ✨ Pour quoi faire ? Classe Active est un outil pour les enseignants du **collège / lycée** (mais adaptable à tout niveau) qui permet de : - Suivre les **points de comportement** par élève, par groupe, ou par classe entière - Gérer plusieurs classes avec leurs propres listes d'élèves, comportements personnalisés, échelle de score - Importer la liste et les **photos** des élèves depuis **Pronote** via bookmarklet (méthode adaptée de [Mathix](https://mathix.fr)) - Faire un **plan de classe** (tables rectangulaires et rondes, drag and drop) - **Tirer au sort** un élève ou répartir en groupes aléatoires - Exporter une **fiche PDF** de la classe (vue d'ensemble + fiches d'identité) - Et surtout — depuis la **version 1.5** — projeter au tableau un **Class Screen** entièrement personnalisable avec timer, feux, roue, groupes, sites web, QR codes et zones de texte (voir plus bas). Toutes les données restent **dans le navigateur de l'enseignant** (localStorage). Rien n'est envoyé sur Internet, sauf si vous utilisez l'export JSON pour partager une session avec un collègue. --- ## 🚀 Démarrer **Aucune installation nécessaire.** Téléchargez le fichier `classevibe.html`, ouvrez-le dans Chrome / Firefox / Safari, et c'est parti. Pour héberger en ligne (école, ENT, GitLab Pages…), uploadez simplement le fichier HTML — pas de build, pas de Node, pas de dépendances. Vous pouvez aussi l'utiliser **hors-ligne** : ouvrez la page une fois, puis travaillez sans Internet (sauf pour les avatars Lorelei qui sont récupérés en CDN — voyez plus bas pour les détails). --- ## 🟦 Class Screen — Tableau personnalisé Nouveauté majeure de la **version 1.5** : depuis n'importe quelle classe, cliquez sur le bouton **🟦 Class Screen** dans la topbar pour ouvrir un tableau plein écran inspiré de [Classroom Screen](https://classroomscreen.com). Vous pouvez y composer un tableau avec autant de widgets que voulu : | Widget | Description | |---|---| | ⏱️ **Timer** | Compte à rebours ou chronomètre, anneau de progression SVG, bip sonore, alerte rouge à 10 s. Choix « décompte fluide à la seconde » ou « changement minute par minute » selon ce que vous souhaitez montrer. | | 📝 **Texte** | Zone de texte avec barre d'outils intégrée : police (9 choix dont Comic Sans MS, Verdana, Impact…), taille, gras, italique, couleur, alignement. | | 🚦 **Feux** | Vrais feux tricolores SVG, boîtier noir, dégradés et halo lumineux. Cliquez pour activer / désactiver une couleur. | | 🎡 **Roue** | Roue de loterie avec les élèves présents. Labels radiaux (dans le sens de la bande colorée). Bouton « Retirer » pour enlever le gagnant du tirage suivant. | | 👥 **Groupes** | Répartition aléatoire en N groupes (2-20), avec photos Pronote ou prénoms seuls. Cases responsives. | | 🌐 **Site web** | Iframe sécurisée pour intégrer Genially, LearningApps, YouTube, Wordwall, etc. | | 📱 **QR Code** | Génère localement un QR code à partir d'un lien — pour que les élèves le scannent avec leur téléphone. **100 % hors-ligne** (bibliothèque embarquée). | Chaque widget se **déplace** (clic-glisser sur l'en-tête), **redimensionne** (coin bas-droit), passe en **plein écran** (bouton ⛶) ou se ferme (✕). Un clic sur un widget l'amène au premier plan. Vous pouvez aussi mettre un **fond personnalisé** (URL d'image ou couleur unie) via le bouton 🖼️. **Tout est sauvegardé** par classe dans le navigateur : positions, tailles, contenus, état du timer en cours, rotation actuelle de la roue, URLs des sites embarqués, derniers groupes générés, fond personnalisé. Quand vous reviendrez, votre tableau sera exactement comme vous l'avez laissé. Sur mobile (≤ 760 px), les widgets s'empilent verticalement pour rester accessibles. --- ## 📸 Import Pronote Pour récupérer la liste et les photos de vos élèves depuis le trombinoscope Pronote : 1. Sur la page d'accueil, cliquez **📸 Importer depuis Pronote**. 2. Glissez le **bookmarklet bleu** dans votre barre de favoris (un seul clic suffit). 3. Allez sur la page **Trombinoscope** de Pronote (avec photos visibles). 4. Cliquez sur le favori « 📌 Classe Active ← Pronote ». 5. Un fichier `pronote-eleves-AAAA-MM-JJ.json` est téléchargé automatiquement. 6. Revenez sur Classe Active et chargez ce fichier dans le formulaire d'import. La méthode est adaptée de [Mathix](https://mathix.fr) (merci !). Si le bookmarklet ne marche pas (Content-Security-Policy de votre Pronote), une **méthode console** alternative est proposée — il vous suffit de coller le code dans la console F12 de Pronote. **Important** — RGPD : la saisie des noms et photos d'élèves constitue un traitement de données personnelles. Vous devez le **déclarer dans le registre des activités de traitement de votre établissement** ([guide CNIL](https://cnil.fr/fr/RGPD-le-registre-des-activites-de-traitement)). Le rappel apparaît dans les mentions légales de l'app. --- ## 🛠️ Stack technique - **HTML / CSS / JS vanilla** dans un seul fichier (~200 Ko) - **Police** : [Nunito](https://www.bunny.net/fonts/google/Nunito) via [Bunny Fonts](https://fonts.bunny.net) (RGPD-compliant, sans cookie, sans tracking) - **Avatars** : [Lorelei](https://www.figma.com/community/file/1198749693280469639) par Lisa Wischofsky, CC0, servies par [DiceBear](https://www.dicebear.com) - **QR codes** : `qrcode-generator` de Kazuhiko Arase (MIT, ~20 Ko minifié, **embarqué dans le fichier**) - **PDF** : [jsPDF](https://github.com/parallax/jsPDF) chargé en CDN - **Aucune** dépendance npm, aucun build step, aucune compilation ### Architecture des données Toutes les données sont stockées sous le préfixe `cvibe_v5_` dans `localStorage` : - `classes` : array `[{id, nom, level, scoreBase, groupsEnabled, groupLabel, passportEnabled, showPhotos, plan, dashboard}]` - `groups` : `[{id, classId, nom, emoji, img, colorIdx}]` - `eleves` : `[{id, classId, groupId, prenom, nom, score, pointsBonus, pointsMalus, behaviors, absent, avatarSeed, photoData?}]` - `comp_pos`, `comp_neg` : comportements personnalisés - `stamps`, `passport` : tampons et passeports - `journal` : 60 dernières actions (avec undo) Les dashboards Class Screen sont stockés directement dans chaque classe : `cls.dashboard = {widgets: [], background: ''}`. --- ## 🤝 Contributions Le projet est en GPLv3 — vous êtes libres de l'utiliser, l'adapter, le partager.
