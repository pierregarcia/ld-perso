Comment afficher la barre de favoris ?
🍎 macOS : ⌘ + ⇧ + B (Chrome, Edge, Safari, Firefox)
🪟 Windows / 🐧 Linux : Ctrl + Maj + B (Chrome, Edge, Firefox)
Si le glisser-déposer ne fonctionne pas (Safari par exemple), utilisez "Copier le code", puis créez un nouveau favori manuellement (clic droit sur la barre → Nouveau favori) et collez le code à la place de l'URL.
Le bookmarklet génère un fichier pronote-eleves-AAAA-MM-JJ.json.

🛠️ Méthode Console (si le bookmarklet ne fonctionne pas)
Marche partout (Chrome, Safari, Firefox, Edge) même quand le bookmarklet est bloqué.
  1. Ouvrez la page Pronote du trombinoscope (avec les photos visibles).
  2. Ouvrez la console développeur :
    • 🍎 Mac : ⌘ + ⌥ + J (Chrome) ou ⌘ + ⌥ + C (Safari, après avoir activé le menu Développement dans Réglages → Avancés)
    • 🪟 Windows / 🐧 Linux : F12 puis onglet Console
  3. Copiez le code ci-dessous, collez-le dans la console et appuyez sur Entrée.
  4. Le fichier pronote-eleves-AAAA-MM-JJ.json se téléchargera automatiquement.
